## Description
A multi-page website with JavaScript tasks: variables and operators, DOM manipulation, mouse and keyboard events, a calculator and a To-Do app. Every page has a navbar that links to all parts.

| Page | Script | Tasks |
| --- | --- | --- |
| `index.html` | `part1.js` | Task 0 (console.log, alert), Task 1 (variables, operators, strings) |
| `part2.html` | `part2.js` | Task 2 (change text), Task 3 (change styles), Task 4 (add / remove list items) |
| `part3.html` | `part3.js` | Task 5 (mouseover / mouseout), Task 6 (keyup), Task 7 (calculator) |
| `part4.html` | `part4.js` | Task 8 (To-Do list: add, delete, mark as completed) |

## Structure
```
README.md
index.html, part2.html, part3.html, part4.html
style.css
part1.js, part2.js, part3.js, part4.js
```

## How to run
1. Clone the repository or download the ZIP.
2. Open `index.html` in a browser (internet is needed for the Bootstrap CDN).
3. Open the console with F12 to see the output of Task 0 and Task 1.

## How to publish (GitHub Pages)
Repository -> Settings -> Pages -> Source: `main` branch, `/ (root)` -> Save.
